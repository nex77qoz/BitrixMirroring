# План реализации: Двустороннее зеркалирование комментариев Telegram в Открытые линии Битрикс24 и параллельное прямое зеркалирование чатов

Этот документ описывает план доработки бота и сервисов зеркалирования сообщений для одновременной поддержки двух режимов работы:
1. **Прямое зеркалирование чатов (существующее):** Telegram-группы ➔ чаты Битрикс24 (через стандартный REST API чат-бота `imbot.v2.Chat.Message.send`).
2. **Зеркалирование комментариев в Открытые линии (новое):** Комментарии в Telegram-канале (группе обсуждения) ➔ Открытые линии Битрикс24 (через REST API коннекторов `imconnector.send.messages`).

Оба режима полностью независимы и могут работать параллельно на основе конфигурации.

## Задачи реализации

### Задача 1: Расширение конфигурации и настроек
Необходимо добавить поддержку новых переменных окружения в `settings.py` для Открытых линий без изменения существующей логики.

* **Новые переменные окружения (.env):**
  * `BITRIX_OPENLINE_ID` — ID открытой линии в Битрикс24 (например, `5`).
  * `BITRIX_CONNECTOR_ID` — уникальный строковый идентификатор вашего кастомного коннектора (например, `custom_tg_comments`).
  * `TELEGRAM_DISCUSSION_GROUP_ID` — ID группы обсуждения, привязанной к Telegram-каналу.

* **Изменения в коде:**
  * Добавить поля в класс `Settings` в `settings.py`.
  * Добавить парсинг новых переменных с дефолтными значениями (или валидацией).

---

### Задача 2: Добавление методов Connector API в BitrixClient
Для интеграции с Открытыми линиями используются методы семейства `imconnector` REST API Битрикс24.

* **Файлы:** `bitrix_client.py`
* **Методы для добавления:**
  1. `register_connector(self) -> bool` — отправляет запрос к `imconnector.register` для создания типа коннектора на портале.
  2. `activate_connector(self, line_id: int) -> bool` — привязывает коннектор к Открытой линии через `imconnector.activate`.
  3. `send_openline_message(self, ..., text: str) -> bool` — пересылает комментарий в Открытую линию через `imconnector.send.messages`.
  4. `confirm_delivery(self, connector: str, chat_id: str, message_id: str) -> bool` — подтверждает доставку ответа клиенту в Telegram через `imconnector.send.status.delivery`.

---

### Задача 3: Селективная маршрутизация входящих событий Telegram
Доработка логики бота для перехвата комментариев и маршрутизации.

* **Файлы:** `handlers.py`, `mirror_state_store.py`
* **Изменения:**
  * В главном обработчике сообщений Telegram проверять, пришло ли сообщение из группы обсуждения (`TELEGRAM_DISCUSSION_GROUP_ID`).
  * Если сообщение из группы обсуждения и является ответом (комментарием к посту или другому комментарию), вызывать метод `handle_telegram_comment`.
  * В `handle_telegram_comment` извлекать метаданные комментатора (ID, имя, аватар) и ветки комментариев, отправлять в Открытую линию.
  * Сохранять в базе данных SQLite связку `tg_message_id`, `tg_chat_id` и `bx_chat_id` (через новую таблицу `openline_links`), чтобы знать, куда направлять ответы оператора.

---

### Задача 4: Прием ответов от операторов в FastAPI Webhook
Когда ответственный сотрудник отвечает в Битрикс24, событие должно транслироваться в Telegram.

* **Файлы:** `server-side/app.py`
* **Изменения:**
  * Зарегистрировать новый FastAPI эндпоинт `POST /bitrix/connector`.
  * Обрабатывать событие `OnImConnectorMessageAdd` (срабатывает при ответе оператора).
  * Извлекать текст сообщения и ID чата Битрикс24 (`bx_chat_id`).
  * Делать выборку из базы данных для получения соответствующего `tg_chat_id` и `tg_message_id`.
  * Отправлять сообщение в Telegram в виде реплая (`reply_to_message_id`) в нужную группу обсуждения.
  * После успешной отправки в Telegram отправлять статус доставки обратно в Битрикс через `confirm_delivery`.

## Процесс настройки на портале Битрикс24
1. В репозитории запускается скрипт первоначальной настройки, который вызывает REST-метод `imconnector.register` на вашем портале.
2. В интерфейсе Битрикс24 перейдите в **Контакт-центр**. Там появится плитка вашего кастомного коннектора (например, "Telegram Comments Bot").
3. Нажмите на плитку, выберите нужную Открытую линию и активируйте коннектор.
4. Укажите ID открытой линии в вашем файле `.env` (`BITRIX_OPENLINE_ID`).
